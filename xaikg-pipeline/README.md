# xaikg-pipeline — the runtime kernel and the experiments

Python 3.12 package `xaikg` (managed with uv; dependencies pinned in [`pyproject.toml`](pyproject.toml)): data acquisition, LLM extraction, graph loading, the predictor, the explanation runtime used by the generated service, and the experiments. It never re-implements a transformation, a validation rule or a constraint: those are generated by [`xaikg-mde`](../xaikg-mde/), which it calls through [`mde_bridge.py`](xaikg/mde_bridge.py).

Main libraries: pyecore (XMI models), openai (OpenAI-compatible client used for Gemini), neo4j, pandas, scikit-learn, shap, fastapi and uvicorn, jinja2, typer.
